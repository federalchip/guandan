# 掼蛋

一款在浏览器中玩的单人掼蛋游戏。你与三名机器人坐在同一张牌桌上，使用两副牌完成一局固定打 2 的对战。

## 游戏体验

- **四人牌桌：**桌面上你在下方、搭档在上方，两名对手分居左右；窄屏会调整座位排列，方便查看公开牌。
- **清晰的手牌：**你的 27 张牌按点数向上竖叠，牌的底边保持对齐。
- **看得清每一步：**机器人逐步行动，各座位打出的公开牌保留到本轮结束；当前有效的牌集中显示，常见的五张牌无需横向滚动。也可以关闭逐步播放，直接查看最新局面。
- **完成一局：**选择手牌、查看提示、声明牌型、出牌或过牌，直到结算；刷新页面后可以尝试接着玩。

当前提供 **Windows 本地试玩**，公开在线试玩尚未开放。

## Windows 本地试玩

1. 点击仓库的 **Code → Download ZIP**，解压后打开项目文件夹。
2. 安装 [JDK 17](https://adoptium.net/) 和 [Node.js 22.12 或更新版本](https://nodejs.org/)（包含 npm）。
3. 在项目文件夹最外层双击 [`start.cmd`](start.cmd)。脚本会启动游戏，并在准备好后打开浏览器。首次启动需要联网下载依赖，可能要等待几分钟。
4. 在网页中点击“开始一局”。结束后双击项目文件夹中的 [`stop.cmd`](stop.cmd) 关闭游戏服务。

如果浏览器没有自动打开，可在启动窗口显示 `Guandan is ready` 后访问 <http://localhost:5173/>。启动遇到问题时，可查看[开发与排障说明](docs/development.md)。

## 如何操作

轮到你时，点击手牌选牌，再按“出牌”。每按一次“提示”会选中一组当前可出的牌；同一组牌有多种合法声明时，先选择牌型。需要跟牌时也可以按“过牌”。机器人行动会显示在各自座位旁；进行中重新开局需要确认，结算后可以直接开始新的一局。

## 项目技术

前端采用 Vue 3、TypeScript 和 Vite，后端采用 Java 17、Spring Boot。游戏规则、机器人行动和牌局状态由后端处理。开发启动、测试命令及接口资料见[开发与排障说明](docs/development.md)。
